# TSP Speech Database (partial) and Matlab File

*  The folder '48k' contains a total of 1444 .wav speech files with 48 kS/s from 25 talkers.
This is a portion of the speech database generously provided by Peter Kabal at the
Telecommunications & Signal Processing Laboratory (TSP) of McGill University,
and redistributed here according to the terms listed in '48k/Licence.txt'.

*  As of September 10, 2026, this portion of the TSP Speech Database was located at
https://www.mmsp.ece.mcgill.ca/Documents/Data/TSP-Speech-Database/48k.zip
and the entire TSP Speech Database was located at
https://www.mmsp.ece.mcgill.ca/Documents/Data/.

* The folder 'Matlab' contains a .mat file that has been precomputed to support the
TSP multi-talker experiments. It took about 2.5 hours to compute on one platform.
